# wear_the_earth


> A values-driven brand search and AI recommendation system that empowers users to make informed, ethical fashion choices.

👉 **[Watch the Wear The Earth Demo Video on Google Drive](https://drive.google.com/file/d/1Ln7mmoQoy5IPf9GQKNJGsxrxMfuAblLx/view?usp=drivesdk)**

---

## Overview
At its core is an intuitive search interface that provides instant access to a detailed sustainability card for any fashion brand. Each card breaks down a brand’s environmental and social practices into clear, accessible categories—eliminating the need to sift through vague corporate reports or scattered data sources.

---

## Key Features
- **Instant Brand Lookup:** A fast, real-time search interface delivering immediate supply chain data.
- **Material & Environmental Analytics:** Insights into raw material sourcing, textile recycling protocols, and corporate ESG pledges.
- **Supply Chain Transparency Score:** A quantitative score reflecting supply chain clarity and ethical disclosure metrics.
- **Category-Aware AI Recommendations:** When a searched brand scores poorly, the recommendation engine dynamically suggests higher-performing alternatives in the same category using a custom evaluation rubric (**Sustainable / Questionable / Unsustainable**).
